# Known issues

Open defects, required in every submission (AC page 9). A reported blocker is still a blocker: an entry here does not make it acceptable. Add a row when a defect is found; when it is fixed, keep the row and set "In submitted build" to "No (fixed in `<build ID>`)".

Severity: **blocker** (any AC page 9 blocker: crash, progression trap, ignored or duplicated input, wrong volt, refresh or reset behavior, incompatible delivery, missing assets, missing evidence), **major** (a criterion fails on some target, with a workaround), **minor** (cosmetic or feel, no criterion fails).
